🖥️ JAVA 版与基岩版进入方式区别

很多玩家搞不清两个版本的地址填法，其实很简单 —— 群规则里的地址形如 域名:端口，冒号左边是域名（解析出来就是 IP），右边是端口号。

示例地址：9666.fun:23178
冒号左边 = 域名 / IP　冒号右边 = 端口号
版本 填写方式 说明
JAVA 版 只有一个地址栏 地址栏要同时包含 IP 和端口，即填 冒号左边:冒号右边 的完整形式。
基岩版 IP 与端口分开填 IP 一栏填冒号左边（域名解析出来是 IP），端口一栏填冒号右边。
💡 简单记：JAVA 版整串一起填；基岩版拆开 —— 左边填 IP，右边填端口。
